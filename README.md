## 📖 Overview

This repository tracks notable **SaaS platforms** and **open-source projects** building **AI To-Do Lists that do themselves**. These intelligent systems automatically capture tasks, prioritize them, break them down, schedule, delegate to agents, send reminders, update status, and even complete simple tasks autonomously.

### 💡 Platform Highlights

- **[Bond](https://bond.ai/)** 🤖  
  Autonomous AI agent that manages your tasks, schedules, and executes workflows proactively. Ideal for power users using their own API keys.

- **[Motion](https://www.usemotion.com/)** ⚡  
  AI-powered task manager that automatically schedules tasks, prioritizes, and adapts to your calendar.

- **[Taskade](https://taskade.com/)** 🧠  
  AI-native workspace with strong multi-agent support for building autonomous task systems.

- **[ClickUp Brain](https://clickup.com/ai)** 🏠  
  Intelligent AI layer inside ClickUp that auto-generates tasks, summarizes work, and suggests next actions.

## 💻 Open-Source GitHub Projects

### 🏗️ Dedicated Autonomous Task Management Projects

- **[n8n](https://github.com/n8n-io/n8n)** 🔗  
  Powerful open-source workflow automation tool with LLM nodes. Perfect for building self-executing task systems.

- **[Taskwarrior + AI Extensions](https://github.com/GothenburgBitFactory/taskwarrior)** ⚔️  
  Highly respected CLI task management system, easily extended with local LLMs.

- **[LangGraph Task Agents](https://github.com/langchain-ai/langgraph)** 🕸️  
  Stateful multi-agent framework ideal for creating autonomous to-do agents.

- **[CrewAI Task Crews](https://github.com/crewAIInc/crewAI)** 👥  
  Role-based multi-agent orchestration for building self-managing task teams.

- **[OpenWebUI + Task Plugins](https://github.com/open-webui/open-webui)** 🌐  
  Local LLM interface with strong support for building persistent AI assistants.
